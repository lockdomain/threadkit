How X counts characters

Links are always 23X wraps every link with t.co, so a 90 character URL and a 10 character one both cost 23.
Emoji are 2Even long family or flag emoji made of several code points count as 2.
Some scripts are 2Chinese, Japanese and Korean characters count as 2 each, so a full tweet holds 140.
Numbering costs space"12/14" plus line breaks eats 7 characters. ThreadKit reserves it before splitting.
